# Política de privacidad de Zentra

**Última actualización:** 14 de junio de 2026

Esta Política de privacidad describe cómo la aplicación **Zentra** gestiona la información introducida por el usuario.

Zentra es una aplicación de gestión financiera personal que permite registrar gastos, ingresos, categorías, límites mensuales y propósitos de ahorro. La aplicación está diseñada para funcionar de forma local en el dispositivo del usuario.

## 2. Datos que puede introducir el usuario

Zentra permite al usuario introducir y gestionar información como:

* Nombre de usuario o alias dentro de la aplicación.
* Gastos registrados manualmente.
* Ingresos registrados manualmente.
* Categorías de gastos.
* Límites mensuales por categoría.
* Propósitos u objetivos de ahorro.
* Aportaciones a objetivos.
* Preferencias de idioma.
* Preferencias de acompañamiento o recordatorios dentro de la aplicación.
* Imagen de perfil, si el usuario decide añadirla.

Estos datos son introducidos voluntariamente por el usuario para el funcionamiento normal de la aplicación.

## 3. Almacenamiento local

Zentra guarda la información de la aplicación **localmente en el dispositivo del usuario**.

La aplicación puede utilizar almacenamiento local, incluyendo tecnologías como **AsyncStorage** u otros sistemas de almacenamiento interno del dispositivo, para guardar los datos necesarios para su funcionamiento.

Los datos guardados localmente pueden incluir gastos, ingresos, categorías, límites, objetivos, preferencias y configuración de la aplicación.

## 4. No envío de datos a servidores externos

Actualmente, Zentra **no envía los datos financieros del usuario a servidores externos**.

La información introducida por el usuario permanece en el dispositivo, salvo que en el futuro se añadan funciones opcionales de sincronización o copia de seguridad. En ese caso, esta Política de privacidad será actualizada antes de activar dichas funciones.

## 5. No venta de datos

Zentra **no vende, alquila ni comercializa** los datos personales o financieros del usuario.

## 6. No transferencia a terceros

Zentra **no transfiere datos personales o financieros a terceros**.

La aplicación no comparte información del usuario con empresas externas, redes publicitarias, servicios de análisis o intermediarios comerciales.

## 7. No uso de cookies

Zentra **no utiliza cookies**.

La aplicación no emplea cookies publicitarias, cookies de seguimiento ni cookies de análisis.

## 8. No publicidad

Zentra **no muestra publicidad** dentro de la aplicación.

La aplicación no utiliza redes publicitarias ni herramientas de seguimiento asociadas a anuncios.

## 9. Permisos del dispositivo

Zentra puede solicitar algunos permisos del dispositivo únicamente cuando sean necesarios para una función concreta.

Por ejemplo:

* Acceso a la cámara o galería si el usuario decide añadir o cambiar su foto de perfil.
* Permisos de notificaciones si el usuario activa recordatorios o avisos de la aplicación.

Estos permisos son opcionales y dependen del uso que el usuario haga de la aplicación.

## 10. Eliminación de datos

Como los datos se almacenan localmente en el dispositivo, el usuario puede eliminar sus datos de las siguientes formas:

* Borrando los datos de la aplicación desde los ajustes del dispositivo.
* Desinstalando la aplicación.
* Eliminando manualmente los registros dentro de la aplicación, cuando la función esté disponible.

Al desinstalar Zentra, los datos locales asociados a la aplicación pueden eliminarse del dispositivo según el comportamiento del sistema operativo.

## 11. Seguridad

Zentra utiliza el almacenamiento local del dispositivo para guardar la información introducida por el usuario.

El usuario es responsable de proteger el acceso a su dispositivo mediante los métodos de seguridad disponibles, como PIN, contraseña, huella dactilar o reconocimiento facial.

## 12. Menores de edad

Zentra no está dirigida específicamente a menores de edad.

La aplicación está pensada para usuarios que desean gestionar gastos, ingresos y objetivos financieros personales.

## 13. Cambios en esta Política de privacidad

Esta Política de privacidad puede actualizarse en el futuro si Zentra incorpora nuevas funciones, como sincronización en la nube, copia de seguridad, conexión bancaria, inteligencia artificial, lectura de notificaciones o servicios externos.

Cuando se realicen cambios relevantes, se actualizará la fecha de esta política.
